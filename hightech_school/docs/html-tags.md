# Tags HTML do HighTech School

As telas são arquivos PHP que geram HTML para o navegador. A tabela lista as tags encontradas nesta versão escolar.

## Estrutura da página

| Tag | Função na página |
| --- | --- |
| `<html>` | Envolve o documento HTML. |
| `<head>` | Reúne título, metadados e folha de estilos. |
| `<meta>` | Define informações como codificação de caracteres e largura para dispositivos móveis. |
| `<title>` | Define o título da aba do navegador. |
| `<link>` | Carrega o arquivo CSS. |
| `<style>` | Define estilos específicos, como a impressão do certificado. |
| `<body>` | Envolve o conteúdo da página. |

## Organização e texto

| Tag | Função na página |
| --- | --- |
| `<header>` | Apresenta o nome do sistema. |
| `<nav>` | Reúne os links de navegação, que mudam conforme o usuário. |
| `<main>` | Marca o conteúdo principal. |
| `<section>` | Agrupa partes relacionadas, como cursos e formulários. |
| `<article>` | Apresenta um item independente, como um curso. |
| `<footer>` | Mostra o rodapé. |
| `<div>` | Agrupa elementos para organizar o layout. |
| `<h1>` | Define o título principal. |
| `<h2>` | Define o título de uma seção. |
| `<h3>` | Define um subtítulo, por exemplo, de um curso. |
| `<h4>` | Define um subtítulo de nível inferior. |
| `<p>` | Forma um parágrafo. |
| `<strong>` | Dá destaque semântico a um texto. |
| `<small>` | Mostra uma observação auxiliar. |
| `<span>` | Agrupa um trecho curto de texto em linha. |
| `<br>` | Insere uma quebra de linha. |
| `<hr>` | Separa visualmente blocos de conteúdo. |

## Links e listas

| Tag | Função na página |
| --- | --- |
| `<a>` | Cria um link de navegação ou ação. |
| `<ul>` | Cria uma lista sem numeração. |
| `<ol>` | Cria uma lista numerada. |
| `<li>` | Representa um item de lista. |

## Formulários

| Tag | Função na página |
| --- | --- |
| `<form>` | Agrupa campos e envia dados ao PHP. |
| `<label>` | Identifica um campo do formulário. |
| `<input>` | Recebe valores como nome, e-mail, senha ou data. |
| `<select>` | Apresenta opções para o usuário escolher. |
| `<option>` | Define uma opção dentro de `<select>`. |
| `<textarea>` | Recebe textos maiores, como descrições. |
| `<button>` | Envia o formulário ou executa uma ação. |
| `<fieldset>` | Agrupa controles relacionados, como alternativas de uma questão. |
| `<legend>` | Identifica o grupo criado por `<fieldset>`. |

## Tabelas

| Tag | Função na página |
| --- | --- |
| `<table>` | Organiza dados em linhas e colunas. |
| `<thead>` | Agrupa o cabeçalho da tabela. |
| `<tbody>` | Agrupa as linhas de dados. |
| `<tr>` | Define uma linha. |
| `<th>` | Define uma célula de cabeçalho. |
| `<td>` | Define uma célula de dados. |
